# Tool Router
Use mpmath for high-precision numerical exploration.
Use SymPy for symbolic manipulation and quick expression testing.
Use Sage for:
- exact algebra,
- finite fields,
- number theory,
- lattices,
- polynomial rings,
- combinatorial designs.
Use PARI/GP for:
- number theory constants,
- algebraic number recognition,
- L-functions,
- high-speed arithmetic.
Use GAP for:
- finite groups,
- group actions,
- designs involving symmetry.
Use NetworkX for graph prototypes.
Use nauty/traces for graph isomorphism and enumeration.
Use Z3/SAT/ILP for finite constraint search.
Use Lean/mathlib for theorem lookup or formal checking.
Use paper search for methods, not for dumping context.
