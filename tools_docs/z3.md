# Z3

## What it's for
An SMT solver: decides satisfiability of formulas over booleans, integers, reals,
bit-vectors, and arrays, with support for optimization (Z3 `Optimize`). Good for
**finite constraint search** and feasibility/infeasibility certificates.

## When to use it
Per the tool router (`docs/02-tool-router.md`), use Z3/SAT/ILP for finite
constraint search:
- encode a combinatorial construction as constraints and let Z3 find a model;
- prove infeasibility (no construction of a given size exists) — an `unsat`
  result is a certificate.
- For pure CNF, a dedicated SAT solver may be faster (`tools_docs/sat_solvers.md`);
  for linear integer objectives, an ILP encoding may fit better.

## How to call it
Python binding `z3-solver`:

```python
from z3 import Solver, Int, sat
s = Solver()
x, y = Int('x'), Int('y')
s.add(x > 0, y > 0, x + y == 10, x * y == 21)
if s.check() == sat:
    print(s.model())            # x = 3, y = 7  (or 7,3)
```

Research-time search is fine; a **final** answer must not call a solver at scoring
time (`docs/07-final-answer-compliance.md`) — emit the found object explicitly.
