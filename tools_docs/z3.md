# Z3

Status: documented interface; runner stubbed in this pass.

## Purpose

Z3 is an SMT solver for finite constraint solving over booleans, integers, reals, bit-vectors, arrays, and optimization objectives.

## Use when

- A combinatorial construction can be encoded as finite constraints.
- You need a witness or counterexample for a bounded case.
- You need integer/boolean constraints with model extraction.
- You want an `unsat` result for the exact encoded finite problem.

## Do not use when

- The mathematical problem is not faithfully encoded yet.
- You need raw CNF speed; use a dedicated SAT solver.
- You need a human proof of the original theorem; Z3 proves only the encoding.

## Minimal smoke test

```python
from z3 import Distinct, Ints, Solver, sat

x, y = Ints("x y")
s = Solver()
s.add(x >= 0, y >= 0, x + y == 10, Distinct(x, y))
print(s.check())
print(s.model())
```

## Common workflows

### Workflow 1: Find a finite witness

Goal: encode variables, constraints, and extract a model.

Steps: create Z3 variables, add constraints, call `check`, translate model into an explicit object.

Code:

```python
from z3 import Ints, Solver, sat
x, y = Ints("x y")
s = Solver()
s.add(x > 0, y > 0, x * y == 21)
if s.check() == sat:
    print(s.model())
```

Expected output: a model such as `x = 3, y = 7`.

### Workflow 2: Prove bounded infeasibility

Goal: show no object exists for a small parameter value.

Steps: encode all constraints for that parameter, call `check`, and preserve the exact script and output.

Code:

```python
from z3 import Int, Solver
x = Int("x")
s = Solver()
s.add(x > 0, x < 0)
print(s.check())
```

Expected output: `unsat`.

## Typical mathematical objects

Z3 is good for finite integer assignments, boolean matrices, graph colorings, bounded Diophantine searches, bit-vector encodings, scheduling-like constraints, and small optimization models.

## Agent protocol

When using Z3, the agent must:

1. State exactly what mathematical constraints are encoded.
2. Run a toy encoding first.
3. Save code under `experiments/`.
4. Save solver output/model under `experiments/results/`.
5. Record encoding assumptions and conclusions in `notes/attempt_log.md`.
6. Translate any final witness into an explicit candidate independent of Z3.

## Pitfalls

- A bad or incomplete encoding gives meaningless `sat`/`unsat` results.
- Nonlinear integer arithmetic can be slow or incomplete in practice.
- Model values may need careful extraction and type conversion.
- Solver success for bounded cases is not a proof of unbounded claims.

## Final-answer compliance notes

Z3 is a research-time search and certification tool. A final candidate must emit the found witness or formula explicitly and must not call Z3 at scoring time unless the problem explicitly allows solver-backed final answers.
