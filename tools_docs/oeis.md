# OEIS

Status: documented interface; lookup backend stubbed/offline-safe in this pass.

## Purpose

OEIS identifies integer or simple rational sequences and links them to formulas, recurrences, references, and related constructions.

## Use when

- An experiment produces several initial terms of a sequence.
- You need a clue for a closed form, recurrence, or known combinatorial object.
- Sequence references may trigger the retrieval policy.
- You want to compare small computed values against known patterns.

## Do not use when

- You have fewer than several reliable initial terms.
- You would treat a match as proof.
- The sequence is generated from private/hidden benchmark data.
- The problem does not naturally produce discrete sequence data.

## Common workflows

### Workflow 1: Sequence recognition

Goal: identify a sequence generated by small parameter experiments.

Steps: compute at least several terms, query OEIS, record ID/formula as a clue, verify independently.

Code:

```python
terms = [1, 1, 2, 5, 14, 42]
print(",".join(map(str, terms)))
```

Expected output: query terms for Catalan-like recognition.

### Workflow 2: Retrieval bridge

Goal: use an OEIS entry to find papers or named constructions.

Steps: record the OEIS ID, extract references/formulas, then follow `docs/04-retrieval-policy.md`.

Code:

```txt
OEIS ID: A000108
Useful clue: Catalan numbers / recurrence / generating function
```

Expected output: a logged clue, not a proof.

## Typical mathematical objects

OEIS is good for integer sequences, counting functions, recurrence clues, generating functions, named combinatorial families, and references connected to sequence data.

## Agent protocol

When using OEIS, the agent must:

1. Compute at least several initial terms.
2. Query OEIS through the approved backend when available.
3. Treat matches as clues, not proof.
4. Record OEIS ID and formula/conjecture in `retrieved_context.md`.
5. Save generating experiment code under `experiments/`.
6. Verify the formula or recurrence independently before using it.

## Pitfalls

- Many sequences share the same first few terms.
- OEIS comments vary in rigor and source quality.
- A formula may use different indexing than the problem.
- Overfitting to small terms can mislead the search.
