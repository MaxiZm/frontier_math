# Topic Card: Coding Theory

## Scope
Error-correcting codes: maximizing minimum distance and rate, bounds on code
size (Singleton, Hamming/sphere-packing, Plotkin, Gilbert–Varshamov), and
explicit code constructions (Reed–Solomon, BCH, Reed–Muller, LDPC, algebraic-
geometry codes).

## Key methods & tools
Linear-algebra and finite-field arguments; weight enumerators and the MacWilliams
identities; LP / Delsarte bounds for the best achievable parameters; algebraic
constructions over `GF(q)`. Typical tools: **Sage** (finite fields, code
constructions, distance computation), **PARI/GP** (finite-field arithmetic),
**Z3/SAT/ILP** (small existence searches and LP bounds), **GAP** (code
automorphism groups).
